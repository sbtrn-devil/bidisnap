# 此文件是 bidisnap 格式的项目规范
#
# 此文件包含用于重建项目的命令。
# 命令格式：
#   ====== FILE "path"           — 创建/替换文件
#   ====== PATCH "path"          — 替换现有文件内的片段
#   ====== DELETE "path"         — 删除文件
#   ====== MOVE "from" "to"      — 重命名文件
#
# 编辑项目时，请以相同格式在单个可复制的代码片段（类似 MD ```...```）中提供输出。
# 在可能的情况下，优先使用 PATCH 而不是通过 FILE 重新创建整个文件，
# 以减少更改的大小。
#
# ---- 示例 ----
#
# 1) 创建新文件（内容一直延续到下一条命令）：
#
# ====== FILE "src/hello.js"
# console.log("hello");
#
# 2) 使用 PATCH 编辑现有文件。每个 FIND/REPLACE 部分由
#    <<<<<<< FIND、======= 和 >>>>>>> REPLACE 分隔。
#    多个部分可以针对同一个文件。对于小修改（<文件的50%），
#    请使用带有 3-5 行上下文的 PATCH，而不是重新发送整个文件：
#
# ====== PATCH "src/hello.js"
# <<<<<<< FIND
# console.log("hello");
# =======
# console.log("hello, world");
# >>>>>>> REPLACE
#
# 3) 如果文件自身的内容包含看起来像 bidisnap 命令的行
#    （例如记录此格式的 Markdown 文件），
#    请将其内容包裹在分隔符中。分隔符是任意非空白标记。
#    内容位于开始和结束的 ======<分隔符> 行之间的所有内容：
#
# ====== FILE "README.md"
# ======>>>README
# 这是一个内容包含 bidisnap 示例的文件：
# ====== FILE "example.txt"
# ...但由于我们处于 ======>>>README 分隔符内，
# 它被视为内容，而不是新命令。
# ======>>>README
#
