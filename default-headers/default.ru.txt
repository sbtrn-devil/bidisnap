# Этот файл — спецификация проекта в формате bidisnap
#
# Он содержит команды, которые воссоздают проект.
# Формат команд:
#   ====== FILE "path"           — создать/заменить файл
#   ====== PATCH "path"          — заменить фрагмент(ы) внутри существующего файла
#   ====== DELETE "path"         — удалить файл
#   ====== MOVE "from" "to"      — переименовать файл
#
# При редактировании проекта предоставляйте результат в этом же формате,
# в одном копируемом фрагменте кода (аналогично MD ```...```). Где возможно,
# предпочитайте PATCH полному пересозданию файла через FILE, чтобы уменьшить
# размер изменений.
#
# ---- Примеры ----
#
# 1) Создание нового файла (содержимое идёт до следующей команды):
#
# ====== FILE "src/hello.js"
# console.log("hello");
#
# 2) Редактирование существующего файла с помощью PATCH. Каждая секция
#    FIND/REPLACE ограничена строками <<<<<<< FIND, ======= и
#    >>>>>>> REPLACE. Несколько секций могут относиться к одному файлу.
#    Используйте PATCH с 3-5 строками контекста для небольших правок
#    (<50% файла) вместо повторной отправки всего файла:
#
# ====== PATCH "src/hello.js"
# <<<<<<< FIND
# console.log("hello");
# =======
# console.log("hello, world");
# >>>>>>> REPLACE
#
# 3) Если содержимое самого файла содержит строки, похожие на команды
#    bidisnap (например, Markdown-файл с документацией этого формата),
#    оберните его содержимое в разделитель. Разделитель — произвольный
#    токен без пробелов. Содержимое — всё между открывающей и закрывающей
#    строками ======<разделитель>:
#
# ====== FILE "README.md"
# ======>>>README
# Это файл, содержимое которого включает пример bidisnap:
# ====== FILE "example.txt"
# ...но поскольку мы находимся внутри разделителя ======>>>README,
# это трактуется как содержимое, а не как новая команда.
# ======>>>README
#
